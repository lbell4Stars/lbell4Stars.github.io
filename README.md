# LaQuesha Bell — Portfolio

A static HTML/CSS portfolio designed with a dark evergreen, charcoal, and gold editorial visual direction.

## Projects included
- OneTouch — interactive ticket-workspace concept using generated fictional demo data.
- PriceTag — product discovery and price-comparison concept, displayed at Tech Expo on 12.2.26.
- Tecla — Spanish language and touch-typing game concept, displayed at Tech Expo on 12.2.26.

## Run locally
Open `index.html` in a browser. To use the OneTouch demo, open `onetouch/index.html` from the same folder. The demo uses its local generated mock API and does not require a live company system.
